# 🛍️ Nova Gadget Store

A fully functional e-commerce website built with React as part of the **[**Learnex React Mastery Class**](https://www.facebook.com/learnexspace)**.

This project is designed to practice React fundamentals by building a complete gadget store experience, from browsing products to managing a shopping cart and completing checkout.

---

## ✨ Features

- 🏠 Home page with hero section and featured products
- 🛍️ Product browsing and product categories
- 🛒 Add and remove products from the shopping cart
- 💳 Checkout flow
- 🔐 Sign In and Sign Up pages
- 🌙 Light and Dark theme
- 📱 Responsive layout
- 🧭 Navigation with React Router
- 👤 User authentication state
- 🧩 Reusable React components
- 📦 Shared application state using Context API
- ❌ Custom 404 Not Found page
- ✅ Thank You page after checkout

- Create a Light / Dark theme system

- Build responsive layouts with CSS
